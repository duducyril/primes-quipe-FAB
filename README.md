# primes-equipe-FAB
Application mobile de démonstration pour le suivi des primes d'équipe.

## Version HTML

Le fichier `index.html` contient une version web de l'application, facile à partager et à ajouter à l'écran d'accueil sur iPhone.

### Utilisation

1. Ouvre `index.html` dans un navigateur.
2. Sur iPhone, ouvre Safari et charge `index.html`.
3. Appuie sur le bouton de partage puis sélectionne `Sur l'écran d'accueil`.

## Installation React Native

1. Ouvre un terminal dans le dossier du projet.
2. Exécute `npm install`.
3. Lance l'application avec `npm start`.

## Exécution sur smartphone

- Pour Android : `npm run android`
- Pour iOS : `npm run ios`
- Pour le web : `npm run web`

## Description

Cette application est un prototype Expo React Native. Elle affiche un compteur de points et permet de simuler un suivi de prime pour les équipes du mois.
